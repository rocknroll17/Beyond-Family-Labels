# BFL Project Page

Project page for **Beyond Family Labels: A Taxonomic Ornstein–Uhlenbeck Prior for Avian 3D Shape Recovery** (NeurIPS 2026, Oral).

Built on the [Academic Project Page Template](https://github.com/eliahuhorwitz/Academic-project-page-template). Static HTML, no build step.

## Deploy

GitHub → Settings → Pages → Source: `Deploy from a branch`, branch `main`, folder `/ (root)`.

## Local preview

```
python3 -m http.server 8000
```
